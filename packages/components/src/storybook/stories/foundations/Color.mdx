## Using Figma tokens

### Background colors
Our overall look should be light and bright. To achieve that we use:

- `base-white`: This is our main background color.
- `engineering-100`: If it is necessary to apply more section-structure. Especially for dashboard designs.
- `ocean-500`: This option is only recommended for marketing websites by highlighting messages/sections.

### Typography 
- For default text we use `base-black` as main color. On brand or dark colored backgrounds we recommend to use `base-white`.
- For headlines you can use either `base-black` or `ocean-500`. For the homepage in the hero section we recommend to use `ocean-500` as display/h1.
- For interactive texts like inline-links use `ocean-500`.

### Components 
We use a set of engineering color variations to build the core fibres of many layouts and components. This core fibres can be:

- An engineering outline to shape the form of a toggle, text field etc.
- An engineering divider structuring content.
- Engineering backgrounds/borders for tables, rows and columns.

### Interactions 
We use our brand colors to highlight interactive elements and their interaction states.

- `ocean-500`: Default state
- `ocean-600`: Hover state
- `ocean-700`: Pressed state
- `engineering-300`: Disabled state

### Signal information 
As in many user interfaces we also use signal colors to convey information quickly and effectively to the user.

- `green-500`: Used to indicate a successful action.
- `orange-500`: To indicate a warning message.
- `red-500`: To indicate an error message. The two shades `red-600` and `red-700` are used for destructive button states. 

### Interactive infographics 
Sometimes it needs more colors to visualize complex infographics for example on dashboard user interfaces. In these cases we recommend to use these colors:<br/>
