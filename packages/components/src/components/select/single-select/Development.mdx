## Notes

### Options

Options are provided as slotted `ifx-select-option` children. Wrap options in an
`ifx-select-group` to render a non-selectable, greyed group header (like HTML `<optgroup>`):

```html
<ifx-select label="KPI" show-search="true">
  <ifx-select-option value="all">All KPIs</ifx-select-option>

  <ifx-select-group label="Revenue">
    <ifx-select-option value="rev-total">Total revenue</ifx-select-option>
    <ifx-select-option value="rev-region" selected>Revenue by region</ifx-select-option>
  </ifx-select-group>

  <ifx-select-group label="Costs" disabled>
    <ifx-select-option value="cost-op">Operating costs</ifx-select-option>
  </ifx-select-group>
</ifx-select>
```

- Preselect an option by setting `value` on `ifx-select`, or by adding the `selected`
  attribute to an `ifx-select-option`.
- Set `disabled` on an `ifx-select-option` (or on a whole `ifx-select-group`) to make it
  non-interactive.

### Custom events

- `ifxSelect` — emitted when the selection changes. `event.detail` is an object with the
  `value` and `label` of the selected option, or `null` when the selection is cleared.
- `ifxInput` — emitted every time the user types into the search field; `event.detail` is
  the search string.
- `ifxOpen` — emitted when the dropdown opens (`true`) or closes (`false`).
